# MINTSHOP — Bài tập lớn A3
Website bán hàng tĩnh giới thiệu phụ kiện công nghệ, xây dựng bằng HTML5, CSS3 và JavaScript thuần.

## 1. Cấu trúc
- `index.html`: cấu trúc nội dung và các khu vực giao diện.
- `style.css`: giao diện, màu sắc, bố cục responsive.
- `script.js`: dữ liệu sản phẩm, tìm kiếm, lọc danh mục, giỏ hàng và biểu mẫu demo.
- `assets/`: logo và hình minh họa sản phẩm dạng SVG.
- `docs/`: báo cáo A3 và nhật ký sử dụng AI.

## 2. Chạy website
1. Giải nén thư mục dự án.
2. Mở `index.html` bằng trình duyệt hiện đại (Chrome, Edge hoặc Firefox).
3. Không cần cài đặt máy chủ hoặc thư viện ngoài.
4. Để chỉnh sửa, mở thư mục bằng VS Code và sửa các tệp tương ứng.

## 3. Chức năng
- Hiển thị 6 sản phẩm mẫu theo 3 danh mục.
- Lọc sản phẩm theo danh mục.
- Tìm kiếm theo tên hoặc danh mục.
- Thêm sản phẩm, tăng/giảm số lượng, xóa sản phẩm trong giỏ.
- Tính tạm tính và lưu giỏ hàng bằng `localStorage`.
- Biểu mẫu nhận email minh họa.
- Bố cục tương thích desktop, tablet và mobile.

## 4. Phạm vi và giới hạn
Đây là website tĩnh phục vụ bài tập lớn. Chưa có backend, cơ sở dữ liệu, tài khoản người dùng, quản trị sản phẩm, tồn kho, cổng thanh toán hoặc gửi email thật. Nút đặt hàng chỉ mô phỏng luồng thao tác, không phát sinh giao dịch.

## 5. Đưa website lên Internet
Có thể tạo repository GitHub, tải toàn bộ nội dung dự án lên nhánh `main`, sau đó bật GitHub Pages tại Settings → Pages → Deploy from a branch → `main` / root. Sau khi triển khai, mở URL GitHub Pages và kiểm tra lại các chức năng. URL thực tế cần được điền vào báo cáo sau khi triển khai thành công.
